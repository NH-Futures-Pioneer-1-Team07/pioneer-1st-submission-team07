# API 오류 확인·질문·제보 안내

## API 사용 시 확인할 항목

- API 응답의 항목 누락·이름·값·형식·동작과 명세의 불일치.
- 상황과 맞지 않거나 문서에 없는 오류코드·메시지.
- 개발자센터 문서의 오류·누락·오타와 동작하지 않는 예제 코드.
- 공개 REST API 프로그램(NH FUTURES API)의 결함.
- 서버 장애 의심 현상의 발생 시각·대상 API·증상.

## 제보 전 확인

- 모의환경에서 사용한 명세와 실제 요청·응답을 대조. 재현 조건·기대 결과·실제 결과·로그·캡처를 기록하고, 키·토큰·개인정보는 가림.
- 원인이나 재현 여부가 미확인인 현상은 확인 필요로 표시.
- 사용법 질문·내 코드 디버깅은 `#api-질문`에 작성. 사용 미숙·단순 문의는 오류 제보 가점 제외.
- 명세대로 동작하지만 불편한 사항은 ‘개선 제안’으로 표시. 구체적인 개선 제안은 가점 대상이 될 수 있음.
- `#오류-문의`에서 기존 제보 검색. 같은 오류는 먼저 제보한 팀만 인정.

## 가점과 처리 흐름

- **인정된 제보 건당 1~3점, 팀당 최대 10점**을 최종 점수에 가산.
- 재현 절차, 기대·실제 결과 구분, 로그·캡처, 영향·개선 제안이 구체적일수록 높은 가점.
- 운영진 접수 확인 → 재현 결과 안내(확인됨 / 재현 안 됨 / 명세대로 동작 / 추가 정보 요청) → 확인된 오류의 담당 부서 전달. 처리 상황은 해당 글의 스레드에서 확인.

## 오류 제보 양식

게시 위치: `#오류-문의`. 아래 양식을 복사하여 필요한 내용 작성. 응답·로그·캡처의 실제 키·토큰은 가림.

```text
[제보] (한 줄 요약)
팀: team-NN
환경: 모의 / 실전 (서버 주소), 발생 일시
대상: API 이름과 경로 / 문서 페이지 / 프로그램 화면
재현 절차:
  1.
  2.
  3.
기대 결과: (명세·문서 기준으로 이래야 함)
실제 결과: (이렇게 나옴 — 응답·오류코드·메시지, 키·토큰 가림)
로그·캡처: (첨부 또는 저장소 results/ 경로)
영향: (어떤 작업이 막히는지)
개선 제안: (있으면)
```

### 작성 예시

아래 예시의 API 경로·일시·증상은 작성 형식 설명용이며, 확인된 오류가 아님.

```text
[제보] 국내 차트(분) 응답의 거래량 항목이 명세와 이름이 다릅니다
팀: team-07
환경: 모의 (apidemo.futures.co.kr), 2026-10-28 14:10
대상: 국내 차트(분) POST /trade/v1/domestic/chart-minute
재현 절차:
  1. 토큰 발급
  2. {"sym": "A016C000", ...}로 호출
기대 결과: 명세의 항목명 ***
실제 결과: 응답에는 ***로 옴 (캡처 첨부)
로그·캡처: (캡처 첨부 또는 results/ 경로)
영향: 명세 기준으로 파싱하면 거래량이 비어 지표 계산 실패
개선 제안: 문서 항목명 수정 또는 응답 항목명 통일
```

## 질문 양식

게시 위치: `#api-질문`. 아래 양식을 복사하여 필요한 내용 작성. 요청·응답의 실제 키·토큰은 가림.

```text
[질문] (한 줄 요약)
팀: team-NN
환경: 모의 / 실전 (서버 주소)
API: (이름과 경로, 예: 국내 현재가 POST /trade/v1/domestic/price)
하려는 것:
해 본 것:
요청(키·토큰 가림):
응답 또는 오류 메시지:
```

### 작성 예시

아래 예시는 작성 형식 설명용이며, 실제 실행·오류 발생 기록이 아님.

```text
[질문] 접근토큰 발급 뒤 현재가 조회가 401로 떨어집니다
팀: team-03
환경: 모의 (apidemo.futures.co.kr)
API: 국내 현재가 POST /trade/v1/domestic/price
하려는 것: 코스피200 선물 현재가 조회
해 본 것: 토큰 재발급, 헤더 철자 확인
요청: Authorization: Bearer ***, body {"sym": "A016C000"}
응답: 401 {"msg_cd": "EGW***", "msg_cntn": "..."}
```
