# 커밋 규칙

## 형식

```text
weekNN: 변경 내용
```

| 변경 대상 | 접두사 |
|---|---|
| 주차별 과제·보고서·실행 자료 | 해당 주차: `week01`~`week08` |

## 주차 자동 설정

- 모든 커밋의 주차는 [README의 주차별 일정](../README.md#주차별-일정)과 실제 커밋 시점의 한국 시간(Asia/Seoul)으로 계산.
- 제출일 23:59:59까지 해당 주차 적용, 다음 날 00:00부터 다음 주차 적용.
- 사용자가 주차를 지정하면 해당 지시 우선 적용.

## 작성 기준

- 주차 번호는 두 자리로 표기.
- 콜론 뒤 공백 한 칸 사용.
- 변경 내용은 간결하고 구체적으로 작성.
- 작업 종류·목적별로 적절한 범위로 커밋 분리.
- 서로 독립적인 주차별 변경은 커밋 분리.

## 승인 기준

- 커밋별 포함 파일·변경 요약·메시지를 사용자에게 제시.
- 사용자 승인 후 승인된 내용만 커밋.
- 승인 후 내용이나 분할 방식이 변경되면 재승인 요청.

## 예시

```text
week01: 팀 소개 작성
week02: 전략 실행 결과 추가
week02: 실행 명령 수정
```
