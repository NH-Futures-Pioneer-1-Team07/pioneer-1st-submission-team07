# GitHub 작업 안내

모든 작업은 `main`에서 진행.

## 작업 순서

| 단계 | 내용 |
|---|---|
| 1. Pull | 작업 전 GitHub `main`의 최신 내용 받기 |
| 2. 작업 | 필요한 파일 작성·수정 |
| 3. 승인 요청 | 작업 종류·목적별로 커밋을 나누고, 커밋별 포함 파일·변경 요약·메시지를 사용자에게 제시 |
| 4. Commit | [커밋 규칙](commit-convention.md)에 따라 사용자가 승인한 내용만 커밋 |
| 5. Push | 커밋을 GitHub `main`에 업로드 |

## 업로드 금지 항목

- APP Key, Secret Key, 접근토큰, 웹소켓 접속키.
- 계좌번호, 계좌 비밀번호, 주민번호 등 개인정보.
- 실제 값이 들어 있는 설정 파일(`config.yaml`, `.env` 등).

## AI 요청 예시

```text
작업 전 main의 최신 내용을 Pull하고, 다음 작업을 진행해줘: …
작업 후 종류·목적별로 커밋을 나누고, 각 커밋의 포함 파일·변경 요약·메시지를 보여줘.
내가 승인하면 승인한 내용만 커밋하고 main에 Push해줘.
```
