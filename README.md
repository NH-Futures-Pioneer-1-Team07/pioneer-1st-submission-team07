# 미싱링커 (Missing Linker)

**활동 기간:** 2026.10.21 \~ 2026.12.11

## 팀 소개

미싱링커(Missing Linker)는 경영 지식과 소프트웨어 개발 역량을 연결해, 각자의 전공만으로 채우기 어려웠던 부분을 함께 잇고자 모인 팀입니다.

NH선물 REST API의 시세 데이터와 검색량·온라인 언급량 등 비재무적 지표를 연결해 시장의 기대를 분석하고, 선물 매매와 위험관리에 활용할 수 있는 도구를 만들고자 합니다. 주차별 전략 구현과 데이터 검증, 결과 기록·발표, API 질의응답을 통해 아이디어를 구체화하고 결과물을 발전시키겠습니다.
